## 问题与决策

- Docker Desktop 不随系统自启 → 建议开启「Start Docker Desktop when you sign in」
- 平台是 Docker Compose 部署，容器名 `wdxmgz-*`，不要再用旧的 `xgsz-*`
- 旧的 `xgsz-nginx/mysql/redis/mongo` 容器会占用端口导致 compose 起不来 → 启动脚本已自动停掉它们（保留 `xgsz-k8s-control-plane` 集群）
- 若出现「后端连不上 redis/mysql」→ 多为容器网络分裂，执行 `docker compose down && docker compose up -d` 重建网络
- 浏览器可能缓存旧页面，已给 nginx 加 HTML no-cache
