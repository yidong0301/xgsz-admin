# 芯光数智 智能运维平台 · 现场演示脚本

> 版本：v1.0 ｜ 更新：2026-11-06

## 演示流程（按顺序走）

1. **登录 → 首页总览**
   - 展示服务器、GPU 统计卡片
   - 看大盘告警通知

2. **点【资产管理 / GPU 节点】**
   - 查看 CMDB 里的服务器和 GPU 资产台账
   - 验证 GPU 卡号、型号、显存、状态、归属集群

3. **点【推理任务】**
   - 选择模板，提交一条推理任务

4. **观察任务状态**
   - 排队 → 运行
   - 进入详情查看实时日志

5. **停止任务**
   - 任务结束后查看事件记录：`已上报GPU用量记录到Token平台`

6. **打开告警中心**
   - 展示节点、GPU 告警条目

## 演示前检查

- [ ] Docker 容器全部在线（`docker ps` 看到 7 个 wdxmgz-*）
- [ ] 登录 admin/admin123456 正常
- [ ] 演示数据已就绪（4 台 GPU 服务器）
