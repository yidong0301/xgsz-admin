# 芯光数智 智能运维平台 · 实施计划

> 版本：v1.1 ｜ 更新：2026-11-10

## 一、开发原则

1. **小步推进**：一次只做一件事，不一口气做太多
2. **每阶段验收**：完成后让用户验证，通过再进入下一阶段
3. **保持稳定**：改动前后做回归检查，不破坏已有功能
4. **记录留痕**：每次改动写入 `devlog/当日日期.md`

## 三、P2 验收方式

- P2-1：新建发布单 → 审批 → 发布，观察镜像对比、滚动更新、健康检查；回滚恢复上一版本
- P2-2：点开发布单详情，能看到 K8s 状态、Pod 列表、Pod 日志，操作按钮可用
- P2-3：`https://域名` 可登录，HTTP 自动跳 HTTPS，证书可续期
- P2-4：8 个 kubeconfig 均可从 backend 访问，发布单可按集群分发
- P2-5：`python manage.py test apps.ops.tests` 全绿
- 交付：Ubuntu 上解压 `xgsz-admin-ubuntu-*.tar.gz`，执行 `scripts/deploy_ubuntu.sh` 可登录
