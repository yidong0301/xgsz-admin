# 芯光数智 智能运维平台 · 设计规范

> 版本：v1.2 ｜ 更新：2026-11-11（对齐企业后台参考图：浅灰底 + 白卡片 + 蓝色主色）

| 项 | 值 |

| 主色 | `#1677FF`，用于主按钮、选中态、链接、关键数值 |

| 正文 | `#1D2129` |
| 次要文字 | `#4E5969` |
| 辅助/占位 | `#86909C` |

> 说明：采用**浅灰背景 + 白色卡片 + 蓝色主色**的企业后台风格；表格紧凑、留白克制，不使用大面积渐变/高饱和装饰。

## 二、组件规范

- **按钮**：主按钮纯色 `#1677FF`、白字、4px 圆角；次按钮白底、`#D9D9D9` 边框、深色文字；悬停只变边框/底色，不做位移和强投影。
- **表格**：白底、表头 `#F7F8FA`、行高 44–52px、行线 `#F2F3F5`、hover `#F7F9FC`；数字使用等宽数字。
- **徽章**：4px 圆角、12px 字号；浅色底 + 同色文字，不使用大圆角胶囊。
- **输入框/下拉**：高度 32–34px、4px 圆角、边框 `#D9D9D9`；聚焦边框 `#1677FF` + 2px 淡蓝光圈。
- **侧边栏**：白底、13px 文字；选中项 `#E8F3FF` 底 + `#1677FF` 字，4px 圆角；基础入口（工作台 / 资产 / 人员）+ 日常操作（推理任务 / 告警与自检 / 审计日志）+ 底部「高级功能」折叠组（任务编排 / 发布单 / 环境管理 / 运维日志 / 配置关系）。
- **人员管理**：角色在表格中以**纯文字**展示（不放下拉框、不套边框），按“超级管理员 → 管理员 → 交付主管 → 交付工程师 → 技术员 → 未分配”排序，同角色按创建先后排列。
- **角色划分**：角色名称使用浅色 4px 圆角标签（参考图风格），表格列为角色名称 / 角色描述 / 权限范围 / 用户数 / 操作。

## 三、状态表达

- 状态使用 **4px 圆角浅色徽章 + 同色文字**；表格中不混用大圆角胶囊。
- 颜色只表达状态和可点击，不作装饰；同一页面状态色不超过 4 种。

## 四、交互规范（四态）

1. **加载中**：骨架屏或 loading，块状结构与真实内容一致
2. **空数据**：线性图标 + 一句说明 + 可执行动作
3. **加载失败**：写明原因 + 重试按钮
4. **无权限**：锁定图标 + 原因 + 联系管理员

## 五、文案规则

| 原则 | 正例 | 反例 |
|---|---|---|
| 说结果不说过程 | 已提交，等待调度 | 正在提交任务，请稍候 |
| 说后果不说警告 | 将删除 Pod，任务不可恢复 | 此操作危险，请谨慎 |
| 给出口不给拒绝 | 修改请前往 PC 端 | 无权限 |
| 按钮用动词 | 查看日志 | 日志 |

## 六、术语表（固定写法）

- 平台名：**芯光数智**
- 任务状态：**运行中 / 排队中 / 已成功 / 已失败 / 已停止**
- 终止动作：**终止任务**
- 重启动作：**重新拉起 Pod**
- 告警级别：**紧急 / 重要 / 提示**
- 空列表：**暂无数据**
- 加载失败：**加载失败，点击重试**
