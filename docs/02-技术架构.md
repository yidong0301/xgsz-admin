# 芯光数智 智能运维平台 · 技术架构

> 版本：v1.0 ｜ 更新：2026-11-06

## 一、技术栈

| 层 | 技术 |
|---|---|
| 后端 | Django 3.1.7 + DRF 3.12.4 + Celery 4.4.2 + Channels 3 + daphne |
| 数据库 | MySQL 5.7（业务）/ Redis 6（缓存+队列）/ MongoDB 4.4（连接信息） |
| PC 前端 | 单文件 `xgsz-admin-web/app.html`（内联 CSS/JS + base64 Logo） |
| 小程序端 | 微信原生框架 `xgsz-miniprogram/` |
| 部署 | Docker Compose（nginx / backend / celery-worker / celery-beat / mysql / redis / mongo） |
| 反向代理 | Nginx（8080 → 前端静态 + /api 反代 backend:8000） |

## 数据与逻辑分离

演示数据统一放在 `data/demo_data.json`（用户、服务器、GPU 节点、K8s 集群、交换机、光模块、推理任务）。改演示数据只需编辑该 JSON，再执行：

```bash
python tools/seed_from_json.py    # 幂等导入，不会重复
python tools/export_demo_data.py  # 反向：把库里的数据导回 JSON
```

## 三、关键约定

- 接口前缀：`/api/`
- 认证：JWT，请求头 `Authorization: JWT <token>`
- 统一响应：`{errcode, errmsg, data}`
- 分页：`MyPageNumberPagination`
- 超级管理员：`admin / admin123456`

## 四、常用命令

```bash
# 启动（一键）
双击 启动平台.bat

# 手动启动
docker compose up -d

# 停止
docker compose stop

# 重建后端（改代码后）
docker compose build backend && docker compose up -d

# 建表迁移
docker exec wdxmgz-backend-1 python manage.py migrate
```
