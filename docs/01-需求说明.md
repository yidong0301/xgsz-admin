# 芯光数智 智能运维平台 · 需求说明

> 版本：v1.1-demo ｜ 更新：2026-11-06 ｜ 维护：开发组

## 一、项目背景

「芯光数智」是面向企业内部的**算力运维与 AI 推理调度平台**，PC 端主平台为 `xgsz-admin`，覆盖 CMDB 资产、CI/CD 流水线、任务编排、K8s 推理调度。手机端另有微信小程序 `xgsz-miniprogram` 作为随身控制台。

## 二、本次 Demo 范围（重点）

### 1. 资产管理（CMDB）— GPU 台账

- 资产列表增加 **GPU 字段**：GPU 卡号、型号、显存、状态、归属集群
- 准备 **4 台 GPU 服务器**演示数据，每台绑定 1~2 张卡
- 验收：点开「GPU 节点 / 资产管理」，能看到 GPU 台账

### 2. 推理任务页面 — 本次 Demo 核心

- 推理模板选择、提交任务按钮
- 任务列表：状态（排队 / 运行 / 成功 / 失败）、占用 GPU、提交时间
- 任务详情页：GPU 规格、镜像地址、实时日志、停止 / 重启按钮
- 演示流程：提交任务 → 调用 MAS（真实或 mock）→ 状态自动变更 → 日志输出

### 3. 事件联动 — 后台逻辑

- 任务结束后，在「监控自检 / 告警中心 / 事件日志」展示一条记录：
  `已上报 GPU 用量记录到 Token 平台`
- 目的：讲通「算力时长 → 计费平台」的三层链路

## 三、本阶段明确不做（节省时间）

1. 不重新设计页面（当前布局够用）
2. 复杂图表 / GPU 利用率折线图先用静态模拟数据
3. 不做细粒度权限、自动采集脚本、消息队列重试
4. 不碰 APP 相关接口

## 四、整体交付要求

- 程序需要**上传部署**，让别人也能通过域名/公网 IP 访问登录查看
- 开发过程小步推进，**每个阶段完成需用户验证**
- 保持现有功能不回归

## 五、验收标准

| 项 | 验收方式 |
|---|---|
| GPU 台账 | 资产管理页能看到 4 台 GPU 服务器及各卡信息 |
| 推理任务 | 能提交 → 状态排队→运行 → 详情看日志 → 停止/重启 |
| 事件联动 | 任务结束后事件记录出现「已上报GPU用量记录到Token平台」 |
| 现有功能 | 登录、总览、告警中心等原有功能正常 |
