# 芯光数智 智能运维平台 · 导出交付说明

> 用途：把整个平台打包给同事/客户测试。对方解压后按本文档即可运行。
> 更新：2026-11-10

> **Ubuntu 生产部署**：请直接使用 `dist/xgsz-admin-ubuntu-<版本>.tar.gz`（内含 Docker 镜像 + compose + 一键脚本），
> 步骤见 [`docs/09-Ubuntu-Docker部署.md`](09-Ubuntu-Docker部署.md) 或包内 `README-UBUNTU.md`。
> 本文档下面的 zip 方式适用于 Windows/开发机本地演示。

## 一、打包内容

```
xgsz-admin-交付包-<日期>.zip
├─ xgsz-admin\            后端源码（Django + DRF + Celery）
├─ xgsz-admin-web\        PC 前端（app.html + infer.html + PWA）
├─ xgsz-miniprogram\      微信小程序（9 页）
├─ nginx\                 反向代理配置
├─ data\demo_data.json    演示数据（用户/服务器/GPU/任务）
├─ docs\                  开发标准文档（5 份）
├─ devlog\                开发日志
├─ scripts\               开发过程中的一次性脚本（保留备查）
├─ tools\                 数据导入导出 + 打包脚本
├─ docker-compose.yml     容器编排
├─ 启动平台.bat / 停止平台.bat
├─ CLAUDE.md              开发指引
├─ 上线部署文档.md
└─ xgsz-admin-运行说明.md
```

## 二、对方电脑需要什么

| 依赖 | 说明 |
|---|---|
| Windows 10/11 | 或 Linux（命令需微调） |
| Docker Desktop | 已安装并启动 |
| 端口 8080 | 未被占用 |

> 无需安装 Python / MySQL / Redis / MongoDB——全部在 Docker 里。

## 三、对方如何运行（3 步）

```powershell
# 1. 解压 zip 到任意目录，例如 D:\xgsz-admin
# 2. 进入解压目录，双击「启动平台.bat」（或命令行执行）
cd D:\xgsz-admin
docker compose up -d

# 3. 等待约 20 秒，浏览器打开
http://localhost:8080
# 账号：admin / admin123456
```

## 四、首次运行后导入演示数据（可选）

若需要 30 台服务器 / 35 个推理任务等演示数据：

```powershell
# 1. 进入后端容器建表（首次必须）
docker exec wdxmgz-backend-1 python manage.py migrate

# 2. 创建管理员
docker exec wdxmgz-backend-1 python -c "import os,django;os.environ.setdefault('DJANGO_SETTINGS_MODULE','xgsz_admin.settings');django.setup();from apps.account.models import User;u,c=User.objects.get_or_create(username='admin',defaults={'name':'管理员'});u.is_superuser=True;u.is_staff=True;u.set_password('admin123456');u.save()"

# 3. 导入演示数据（在本机 Python 环境或容器内）
python tools/seed_from_json.py
```

## 五、K8s 说明

- **不接 K8s 也能跑**：推理任务提交会自动「演示模式」模拟成功，界面全可用。
- **要接真实 K8s**：把目标集群的 kubeconfig 放到 `kube/config`，在 `docker-compose.yml` 的 backend/celery 服务里挂载 `./kube/config:/root/.kube/config:ro`，并加 `extra_hosts: host.docker.internal:host-gateway`。
- 可参考本项目已有的 `tools/` 与 `docker-compose.yml` 注释。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 登录报 `Unexpected token '<'` | 后端未就绪或容器网络异常 → `docker compose down && docker compose up -d` |
| 端口被占用 | 停掉旧的 `xgsz-*` 容器（`docker stop xgsz-nginx xgsz-mysql xgsz-redis xgsz-mongo`） |
| 数据库连不上 | 执行 `docker compose down && docker compose up -d` 重建网络 |
| 页面是旧版 | Ctrl+F5 强刷 |

## 七、安全提醒（重要）

- `.env` 里的数据库密码、密钥是**演示默认值**，正式上线前必须修改。
- `admin / admin123456` 是演示账号，正式环境请改强密码。

## 八、Ubuntu 服务器 Docker 交付（生产）

```bash
# 1. 打包（开发机）
python tools/build_ubuntu_package.py

# 2. 上传到 Ubuntu
scp dist/xgsz-admin-ubuntu-<版本>.tar.gz root@服务器:/opt/

# 3. 解压、配置、部署
cd /opt
tar -xzf xgsz-admin-ubuntu-<版本>.tar.gz
cd xgsz-admin-ubuntu-<版本>
cp .env.ubuntu.example .env && vi .env
sudo bash scripts/deploy_ubuntu.sh
```
